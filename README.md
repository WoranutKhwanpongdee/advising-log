# AdvisingLog

A web-based student advising system designed to replace the current paper-and-email process.

The system helps manage student-advisor meetings, advising records, follow-ups, documents, dropout/leave cases, and AUN-QA reporting.

## User Roles

- Student
- Advisor
- Program Chair / QA Coordinator
- Admin

## Tech Stack

- React + Vite + TypeScript
- Tailwind CSS + shadcn/ui
- Cloudflare Workers + Hono
- Cloudflare D1 + Drizzle ORM
- Zod
- Recharts
- SheetJS
- Vitest + Playwright
